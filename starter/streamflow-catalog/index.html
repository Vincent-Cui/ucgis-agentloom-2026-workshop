Title

Catalog UI for 6 selected USGS NWIS streamflow gages in Florida, backed by a vendored 24-hour NWIS Instantaneous Values (IV) snapshot. The map and station list are populated by parsing the JSON.

Provenance

This dataset comes from the U.S. Geological Survey (USGS) National Water Information System (NWIS), using the Instantaneous Values (IV) service. The USGS publishes these data as US Government works (public domain).

In plain language: it is a 24-hour slice of streamflow measurements for a small set of Florida river gages. (In NWIS terms, this page requests parameter 00060 = discharge and a PT24H time window.)

Acquisition

The page fetches a vendored snapshot JSON via a relative path from starter/streamflow-catalog/: ../../data/snapshots/d3-usgs-nwis-fl-stations-24h.json. If fetch() fails under file://, serve the repo root with python -m http.server 8766 and open http://127.0.0.1:8766/starter/streamflow-catalog/.

Data shape

The source file is JSON. It contains (1) station metadata (name and latitude/longitude) and (2) a short time series of recent streamflow measurements for each station.

For each value.timeSeries[i] we read:

  • Station id and name (the NWIS site number and a human-readable station name)
  • Site name: sourceInfo.siteName
  • Coordinates (EPSG:4326): sourceInfo.geoLocation.geogLocation.{latitude,longitude}
  • The measured variable (here: discharge / streamflow; units are ft³/s)
  • A “no data” sentinel value used to represent missing measurements (typically -999999)
  • Observations: values[0].value[] entries with value (string), dateTime (ISO 8601 with offset), and qualifiers.

Processing

The JavaScript fetches the snapshot, iterates value.timeSeries[], and builds one station record per time series. It reads the no-data sentinel from ts.variable.noDataValue (fallback -999999) and filters out observations equal to that sentinel per knowledge:domain:nwis-iv-no-data-sentinel. For each station it selects the most recent non-sentinel observation (by dateTime) and uses it for marker popups and the sidebar list.
